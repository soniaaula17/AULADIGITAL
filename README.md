# AulaDigital

App para docentes con cuentas individuales. Cada usuario que se registra
tiene sus propios datos guardados en la nube (Netlify Blobs), aislados de
los demás usuarios.

## Cómo desplegar (ver guía completa en la conversación con Claude)
1. Sube esta carpeta a un repositorio de GitHub.
2. Entra a https://app.netlify.com -> "Add new site" -> "Import an existing project".
3. Conecta el repositorio. Netlify detecta `netlify.toml` automáticamente.
4. Deploy. Listo: tu app queda en una URL tipo https://tu-sitio.netlify.app
